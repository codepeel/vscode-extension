## 💬 Support & Issue Reporting

For bug reports, questions, and feature suggestions, please use the **[GitHub Issues](https://github.com/codepeel/vscode-extension/issues)** section of this repository.

When reporting a bug, please include:
- Extension version
- VS Code / Cursor / Windsurf version
- Operating system
- Steps to reproduce the issue
- Relevant error logs from the CodePeel output channel
